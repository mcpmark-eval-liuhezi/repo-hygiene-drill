# Support Policy

## Supported versions

This repository provides maintenance and support for the **latest published release** only.

| Version | Supported |
| ------- | --------- |
| latest  | ✅ Supported |
| older   | ❌ Not supported |

## Reporting an issue

- Check the existing issues before opening a new one, to avoid duplicates.
- Open a new issue describing the problem, the steps to reproduce it, and your environment.
- Please do not use the issue tracker for general questions.

## Supported vs. unsupported requests

**Supported:**
- Bug reports against the latest release.
- Documentation corrections.
- Security vulnerabilities (please report these privately — see below).

**Not supported:**
- Feature requests are welcome but are triaged separately and are not guaranteed a response.
- Questions about unsupported or outdated versions.

## Response times

This is a maintainers' practice repository. Issues are triaged on a best-effort basis, and we aim to respond within five business days of the report.

## Security

Security vulnerabilities are handled out-of-band. Please open a private security advisory rather than a public issue, and include reproduction details. We will respond as quickly as we can.

## End-of-life policy

When a new release ships, the previous release enters a 30-day grace window for critical fixes only. After that window, the release is end-of-life and no further fixes are provided.
